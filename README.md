# armv7m-decoder

Instruction decoder for the ARMv7-M (Thumb) architecture, written in Python.  
Generated by [decoder-forge](https://github.com/chgroeling/decoder-forge).

## Install

```bash
uv add armv7m-decoder
```

## Usage

```python
from armv7m_decoder import decode, Context

ctx = Context()
result, n_bytes = decode(instr, ctx)
```

## CLI

```bash
armv7m-decoder decode firmware.bin --start-address 0x0
```
